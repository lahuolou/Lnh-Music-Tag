# 源码审查与本轮变更记录

## 本轮修改

- 插件 ZIP 导入：插件名和入口/面板路径校验；拒绝重复路径、路径穿越和不支持的特殊文件；增加条目数量上限。
- 插件升级：先在同一文件系统 staging 目录解压与校验，再切换正式目录；切换失败尝试恢复旧目录。
- 插件 API：增加 `apiVersion`，当前支持 v1；旧清单未声明版本时默认 v1，未知版本拒绝导入。
- Navidrome 登录：登录请求体限制 1 MiB；过大返回 413，格式错误的 JSON 返回 400。
- Navidrome 分页：在解析层对负数参数 clamp；页大小限制为 1000；切片层二次保护；列表响应中的 nil slice 统一转换为 `[]`，空结果使用 `Content-Range: items */N`。
- 手机 UI 源码：窄屏曲库使用歌曲卡片，保留封面、歌名、歌手、专辑、歌词/时长/码率和编辑入口；任务进度固定在安全区上方；弹窗适配手机高度和安全区。
- 新增分页、登录请求体、插件路径/原子替换、管理 API 认证/CSRF、SQLite 并发测试和 10k 曲目基准测试。

## 安全审查结论（静态）

- 管理 `/api/` 路由在主路由中统一经过会话认证、CSRF 和请求体限制中间件；新增管理接口必须继续挂载到该受保护子路由。
- Subsonic/Navidrome/Jellyfin/Emby 协议路由独立于浏览器 session，需要分别验证其协议认证。
- 第三方插件仍以服务进程权限执行，不是沙箱；原子升级不能替代插件来源信任、签名验证或进程隔离。
- 应继续检查所有状态变更路由是否误用 GET，以及日志/错误响应是否泄露凭证或本地路径。

## 必须保留的分页契约

1. 空列表 JSON 字段必须是 `[]`，不能退化成 `null`。
2. 在解析层对负数分页参数 clamp；切片层仍需二次防御。
3. 对空结果返回合法的空范围，不生成负结束索引。
